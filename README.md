# 📝 My Todo Website

Hi! This is my Todo Website project, which I made to practice my web development skills. It helps users add their daily tasks, mark them as completed, and delete tasks when they are no longer needed.

## ✨ Features

- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Simple and easy-to-use design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js

## 📂 Files Used

- `index.html` – Creates the structure of the website.
- `style.css` – Adds colors and styles to the website.
- `first.js` – Handles the tasks and button actions.
- `server.js` – Runs the server and manages the tasks.
- `package.json` – Contains project information and dependencies.

## ▶️ How to Run

1. Install Node.js.
2. Open the project folder in VS Code.
3. Open the terminal and run:

   ```bash
   npm install
   ```

4. Start the server:

   ```bash
   node server.js
   ```

5. Open your browser and visit `http://localhost:3000`.
